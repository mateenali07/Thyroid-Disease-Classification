# 🩺 ThyroAI – Thyroid Disease Classification

A Machine Learning-based web application for Thyroid Disease Classification using Python and Streamlit.

## 📌 Project Overview

ThyroAI is a machine learning project designed to classify thyroid-related health profiles based on user-provided medical features.

The application provides an interactive interface where users can enter relevant information and receive model predictions.

## 🚀 Features

- Interactive Streamlit web application
- Machine Learning-based classification
- User-friendly interface
- Real-time predictions
- Pre-trained model integration using Joblib

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Jupyter Notebook

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Thyroid-Disease-Classification.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

## 📊 Dataset

The project uses a thyroid disease dataset (`thyroidDF.csv`) for machine learning model development and training.
